# Hallelujah Abdissa — Personal Portfolio

Personal portfolio site for **Hallelujah Abdissa** — independent developer & consultant
based in Addis Ababa, Ethiopia. Built as a Vue 3 single-page app and shipped as a
single Docker container.

- Dark / light theme with persisted preference
- Custom cursor (lerp blob + dot, hover-state pickup)
- Hero with per-letter hover lift, dual scrolling marquees
- Project mosaic with case-study modal — gallery & lightbox for the Power Platform
  showcase
- CV download served as a static asset
- One-command Docker deploy, single `docker-compose.yml`

---

## Run with Docker (one command)

```bash
docker compose up --build
```

Open <http://localhost:8080>.

| Action | Command |
|---|---|
| Start (foreground, logs visible) | `docker compose up --build` |
| Start in the background | `docker compose up -d --build` |
| Tail logs | `docker compose logs -f` |
| Stop & remove the container | `docker compose down` |
| Health check (returns `ok`) | `curl http://localhost:8080/healthz` |

The build pipeline is multi-stage: a `node:20-alpine` builder runs `npm install` +
`vite build`, then the static `dist/` is copied into a `nginx:1.27-alpine` runner.
The image ships gzip + immutable asset caching + sensible security headers.

---

## Run locally without Docker

Requires Node.js 20 or newer.

```bash
npm install
npm run dev      # http://localhost:5173 with HMR
npm run build    # type-check + production bundle to ./dist
npm run preview  # serve ./dist on http://localhost:4173
```

## Deploying

### Option 1 — Any Docker host (recommended)

Anywhere with Docker Engine + Compose (a VPS, Fly.io, Render, an Azure VM, a Pi):

```bash
git clone <this-repo>
cd Personal_Portfollio-V2
docker compose up -d --build
```

Put your reverse proxy / TLS terminator (Caddy, Nginx, Traefik, Cloudflare Tunnel,
etc.) in front of port `8080`. The container exposes `/healthz` for uptime monitors.

To change the host port, edit `docker-compose.yml`:

```yaml
ports:
  - "8080:80"   # host:container — change the left side
```

### Option 2 — Static hosting (Vercel, Netlify, GitHub Pages, S3, Cloudflare Pages)

The build output in `dist/` is a plain static SPA. Push it to any static host.

Generic settings for Vercel / Netlify / Cloudflare Pages:

| Field | Value |
|---|---|
| Build command | `npm run build` |
| Output directory | `dist` |
| Node version | `20` |
| SPA fallback | `/* → /index.html` |

GitHub Pages: run `npm run build`, push the `dist/` contents to a `gh-pages`
branch (or use a workflow). Set `base` in `vite.config.ts` if the site is served
from a subpath.

## Editing content

All copy and project data lives in **one file**: `src/data/content.ts`. Add,
remove, or reorder projects and skills there — components iterate the arrays.

```ts
// src/data/content.ts
export const PROJECTS: Project[] = [
  {
    id: 'movn',
    title: 'Movn Platform',
    // ...
    link: 'movnbids.com',
    href: 'https://movnbids.com/',  // omit to hide the Visit button
    gallery: [...],                  // omit if the project has no images
  },
  // ...
];
```

| Want to… | Edit |
|---|---|
| Change name, role, statement, email, CV link | `HERO` constant in `src/data/content.ts` |
| Add / reorder projects | `PROJECTS` array — set `span` to `tall` / `half` / `wide` for the mosaic layout |
| Add a Power Platform screenshot | Drop a file into `public/showcase/` named `power-apps-NN.png` / `power-automate-NN.jpg` / `power-bi-NN.png` / `sharepoint-NN.png`, then bump the count passed to `range()` |
| Swap social links | `SOCIALS` array |
| Edit skills | `SKILLS` array (three groups, each with 3–5 items) |
| Tune colour tokens | top of `src/styles/global.css` (`--green`, `--purple`, `--yellow`, etc.) |
| Replace the logo | Drop a new `public/logo.png` (favicon + topbar mark) |
| Replace the CV | Drop a new `public/Hallelujah-Abdissa-CV.pdf` |

The Power Platform gallery is generated by a `range()` helper at the top of
`PROJECTS`; change the counts there to match your filenames.

## Project layout

```
src/
  App.vue                # composes all sections
  main.ts
  styles/global.css      # design tokens + every component style
  data/content.ts        # PROJECTS, SKILLS, SOCIALS, HERO copy
  composables/
    useTheme.ts          # dark/light, persisted to localStorage
    useReveal.ts         # IntersectionObserver reveal-on-scroll
  components/
    TopBar.vue           # logo mark, nav, theme toggle
    Cursor.vue           # rAF lerp blob + dot
    Hero.vue
    Marquee.vue
    About.vue
    Skills.vue
    Projects.vue
    ProjectCard.vue
    ProjectModal.vue     # gallery + lightbox
    Contact.vue
    SiteFooter.vue
    icons/               # Arrow, Star, Shape

public/                  # static assets served at the site root
  logo.png
  Hallelujah-Abdissa-CV.pdf
  showcase/              # Power Platform screenshots

Dockerfile               # multi-stage: node-builder → nginx
docker-compose.yml       # one-command entry point
nginx.conf               # SPA fallback, gzip, security headers, /healthz
vite.config.ts
tsconfig.json
package.json
```
